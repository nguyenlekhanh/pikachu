TikFinity integration

Connection

TikFinity Desktop must run on this PC with its Event API enabled. The adapter only reports "connected" after the socket is actually open. If it is offline the game keeps running.

Mock mode & test events

Troubleshooting

  1. Open TikFinity Desktop and log in, then connect your TikTok account.
  2. Enable the Event API / local WebSocket feature in TikFinity (default ws://localhost:21213/).
  3. Make sure port 21213 is not blocked and no other app is bound to it.
  4. Send a test comment in TikFinity's Event Simulator and watch "last event" above.
  5. If the status stays red, the game is still fully playable through mock mode.

Full guide: docs/TIKFINITY_SETUP.md
